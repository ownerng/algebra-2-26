Te faltan 5 cables macho–macho. Los jumpers macho–hembra sirven para el sensor, pero el servo trae un conector hembra y la protoboard también es hembra, así que ahí necesitas macho en las dos puntas. Opciones: compra un paquete de jumpers macho–macho (unos $3.000–$5.000) o hazlos gratis con cable UTP de red: corta 5 trozos de 10–15 cm, pela 7 mm en cada punta y úsalos como jumpers. El alambre sólido del UTP entra firme en la protoboard y en el conector del servo.
Si tu protoboard es mini (170 puntos, sin rieles): no tiene filas + y −. Mete el capacitor directo en los huecos libres de las columnas VIN y GND y conecta el servo a esas mismas columnas usando la fila J y los huecos que queden libres en cada columna.
Diagrama 1 · Vista superior

Conexiones en la protoboard

Pasa el cursor sobre un paso de la lista o sobre la leyenda para resaltar ese cable en el dibujo.

ESP32 con la antena a la izquierda y el USB a la derecha. Sus pines quedan en las filas B e I, columnas 6 a 20; los cables entran por las filas A y J, que quedan libres. Cada hueco está a 2,54 mm del siguiente. Los colores de cable son una sugerencia: lo importante es el pin de destino. Si tu placa tiene 38 pines, las columnas cambian; guíate por el nombre impreso junto a cada pin.

Solo usas el riel inferior. El sensor va directo a los pines del ESP32 (fila A), así que el riel superior queda libre. El riel inferior lleva 5 V y GND para el servo y el capacitor. Nunca conectes el riel de 5 V al pin 3V3: eso daña el ESP32.

Diagrama 3 · Montaje mecánico

El sensor sobre el servo

La posición física del sensor define el sistema de coordenadas local. Si lo montas bien, las fórmulas de la web funcionan sin correcciones raras.

Reglas de montaje

  • Fija el servo a la base con silicona caliente o con los tornillos que trae por las orejas laterales. Sin cinta doble faz, también sirven cinta aislante o amarres plásticos. Si la base se mueve, el mapa se deforma.
  • Haz un soporte en L de cartón y pégalo con silicona al brazo del servo. Pega ahí el sensor con el lente mirando hacia afuera, lo más centrado posible sobre el eje de giro. No pongas silicona sobre el lente.
  • Mide la distancia d entre el eje y el lente. Ese valor se suma a cada lectura antes de rotar.
  • Pon el lente a una altura h que corte los objetos: unos 10–15 cm para patas de sillas y mesas.
  • Deja holgura en los cables del sensor para que el giro de 180° no los tense ni los desconecte.
  • Alcance útil del VL53L0X: hasta unos 1,2 m en modo normal. Superficies negras o brillantes devuelven menos luz.

Lo que esto significa en la matriz

xy = cos θ−sin θsin θcos θ r + d0

Ejemplo con θ = 60°, r = 400 mm y d = 20 mm: x = 420 · 0,5 = 210 mm, y = 420 · 0,866 ≈ 363,7 mm.

Calibración: con el servo en 90° el sensor debe apuntar al frente (+y). Si en 0° apunta a la izquierda en vez de a la derecha, usa θ = 180° − ángulo del servo en la web.

Cuando algo falla

Alimentación y fallas comunes

Si el ESP32 se reinicia cuando el servo se mueve (en el monitor serial aparece Brownout detector was triggered), el USB no alcanza a dar la corriente del servo. Primero revisa el condensador de 1000 µF. Si sigue pasando, alimenta el servo con una fuente de 5 V de 1 A o más: su + al riel inferior +, su − al riel inferior −, y quita el cable de VIN (J20) al riel. La tierra debe seguir siendo común.
SíntomaCausa probable y arreglo
“VL53L0X no encontrado”SDA y SCL invertidos, el sensor sin 3.3 V o un jumper hembra flojo. Revisa los pasos 7 a 10.
Lecturas de 8190 mm o saltos grandesNo hay objeto dentro de 1,2 m o la superficie es oscura o brillante. El programa de prueba descarta las lecturas fuera de rango.
El servo zumba en 0° o 180°Llega al tope mecánico. Limita el barrido a 5°–175° o ajusta los pulsos en servo.attach().
El servo tiembla todo el tiempoFalta tierra común o el cable de señal está suelto en J18.
La PC no reconoce el puertoCable USB solo de carga, o falta el driver CP2102 o CH340 según tu placa.
“Failed to connect” al subir el códigoMantén presionado BOOT cuando aparezca “Connecting…” en el IDE.
Prueba del circuito

Programa de prueba

Las librerías ESP32Servo y Adafruit_VL53L0X ya quedaron instaladas en tu Arduino IDE. El firmware completo del proyecto, con pausa y centrado desde la web, está en firmware/escaner_lidar/. Abre el monitor serial a 115200 baudios: debes ver una línea JSON por cada ángulo, el mismo formato que leerá la interfaz web.

#include <Wire.h>
#include <ESP32Servo.h>
#include <Adafruit_VL53L0X.h>

const int SERVO_PIN = 13;
const int PASO      = 2;    // grados entre lecturas
const int ESPERA_MS = 40;   // tiempo para que el servo llegue

Servo servo;
Adafruit_VL53L0X lidar;

void setup() {
  Serial.begin(115200);
  Wire.begin(21, 22);                  // SDA, SCL
  if (!lidar.begin()) {
    Serial.println("{\"error\":\"VL53L0X no encontrado\"}");
    while (true) delay(1000);
  }
  servo.setPeriodHertz(50);
  servo.attach(SERVO_PIN, 500, 2400);  // pulso min y max del SG90 en µs
}

void medir(int angulo) {
  servo.write(angulo);
  delay(ESPERA_MS);
  VL53L0X_RangingMeasurementData_t m;
  lidar.rangingTest(&m, false);
  if (m.RangeStatus != 4) {            // 4 = fuera de rango
    Serial.printf("{\"r\":%d,\"theta\":%d}\n", m.RangeMilliMeter, angulo);
  }
}

void loop() {
  for (int a = 0; a <= 180; a += PASO) medir(a);
  for (int a = 180; a >= 0; a -= PASO) medir(a);
}
