\section{Objetivos}

\subsection{Objetivo general}

Desarrollar un mapeador 3D de bajo costo que, a partir de una fotografía tomada
con la cámara de un celular, obtenga un modelo tridimensional de un objeto o de
una habitación, usando vectores, matrices y sistemas de ecuaciones lineales
como base matemática.

\subsection{Objetivos específicos}

\begin{enumerate}
  \item Separar, mediante software, el objeto del fondo de la fotografía.
  \item Implementar la reconstrucción en 3D de objetos y de habitaciones a
        partir de una fotografía.
  \item Mostrar el resultado en una página web interactiva, donde el modelo se
        pueda girar, acercar y descargar.
\end{enumerate}
