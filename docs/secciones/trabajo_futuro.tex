\section{Trabajo futuro}

\begin{itemize}
  \item \textbf{Calibrar la cámara.} Medir $f$, $c_x$ y $c_y$ con fotos de un
        tablero de ajedrez, en lugar de suponer el ángulo de visión. Es un
        problema de mínimos cuadrados.
  \item \textbf{Medir la distancia.} Volver a usar el sensor láser de la
        versión anterior junto al celular para conocer $Z_0$ y obtener medidas
        reales en milímetros.
  \item \textbf{Más vistas y una base giratoria.} Con un plato que gire en
        ángulos conocidos, las matrices de rotación serían exactas y se podrían
        usar muchas más vistas.
  \item \textbf{Concavidades.} Combinar la envolvente visual con la
        profundidad estimada por una red neuronal para recuperar huecos.
\end{itemize}
