\section{Trabajo futuro}

\begin{itemize}
  \item \textbf{Medir la distancia.} Volver a usar el sensor láser de la
        versión anterior junto al celular para conocer $Z_0$ y obtener medidas
        reales en milímetros en los objetos.
  \item \textbf{Validar las habitaciones.} Comparar las medidas de
        habitaciones reales (alto, ancho, distancia a las paredes) con las de
        un flexómetro.
  \item \textbf{Varias fotos de un mismo espacio.} Unir fotos tomadas desde
        distintos puntos de una habitación para ver también lo que una sola
        foto no alcanza a mostrar.
\end{itemize}
